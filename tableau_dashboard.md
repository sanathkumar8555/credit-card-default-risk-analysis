# Credit Card Default Risk Analysis Dashboard

## Live Interactive Dashboard

[View Tableau Dashboard](https://public.tableau.com/app/profile/sanath.kumar5850/viz/Credit_Card_Default_Risk_Analysis/Dashboard1?publish=yes)

## Dashboard Features

- Total customers and defaulted customers KPI cards
- Default and non-default customer distribution
- Default rate by September repayment status
- Default rate by number of delayed months
- Credit limit versus repayment risk heatmap
- Default versus non-default distribution by age group
- Interactive filters for age group, education, gender, and repayment risk segment
